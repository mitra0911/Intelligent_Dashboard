Ground rules (read once)

  • No live integrations. All numbers, timelines, and tool names are generated in the browser by createMockData(seed, { scenario }).
  • Single source of truth: MockDataProvider holds one MockDataBundle. Every page reads via useMockData() so Refresh + All healthy stay consistent.
  • Correlation here means: the same bundle pre-joins related fields (anchors, incident ids, service ids, tool labels). There is no streaming join engine, query service, or trace-id resolver—only deterministic mock builders.

Key files

src/data/mockData.ts — all synthetic inputs src/context/MockDataContext.tsx — seed + scenario + refresh src/types.ts — TypeScript contracts for rows you render

How correlation works in this codebase

What we tell the story with (anchors)

Across Command Center and each incident we surface CorrelationAnchorSet: a shared time window, a synthetic correlation_id string, per-tool shadow ids (Datadog, Splunk, Kentik, Grafana, ServiceNow), and services involved derived from affected business services.

What is NOT happening

  • No API calls to Datadog/Splunk/ServiceNow; no OAuth; no webhooks receiving real payloads.
  • Timeline rows (TimelineSignal) are templates rotated per incident—the text names tools; the join is narrative + shared ids in the same JSON object, not a join algorithm.

What IS honest to demo

The architecture intent: production would ingest each tool with timestamps + correlation/trace ids + service keys, then persist or stream into a correlation service. This UI shows what that fused object could look like.

“Correlation” cheat sheet (for your own notes)

  1. Same key everywhere: incident id keys list row, detail object, anchor object, and (where present) event-cluster incidentId.
  2. Same key for services: svc-N ties Command Center tiles, topology roll-up, health drilldown, trace workspace selection.
  3. Time alignment (mock): anchor windows use durationMin / opened minutes; timeline uses negative minute offsets from the same incident object.
  4. Cross-tool text: timeline detail strings explicitly mention Splunk/Datadog/Kentik together—pedagogical correlation for demos.
  5. Traces chart coupling: infra/app/network series share spike logic in the generator—visual “they moved together.”

Refresh & All healthy — what to expect

  • Refresh picks a new seed → entire MockDataBundle recomputes. Incident ids, anchor suffixes, chart points, and tables all shift together.
  • All healthy sets scenario flag → generators produce green services, empty activeIncidents, calm series, and stub incident detail on the primary id for anchor card continuity.
